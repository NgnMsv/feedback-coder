How it works

  1. Codebook. Eight codes, each with a definition, include/exclude rules and examples (codebook.yaml).
  2. Prompt. The codebook and a batch of 10 comments go to the model, which must answer in a fixed JSON shape.
  3. Validate. The answer is checked against a schema; if it is invalid, the error is sent back and the model retries.
  4. Verify. Unknown codes and quotes that do not appear in the comment are dropped; low confidence goes to review.
  5. Evaluate. The result is compared with human labels: precision, recall, F1 and Cohen's kappa per code.
  6. Report. Themes, quotes, disagreements and the review queue, in this page.
